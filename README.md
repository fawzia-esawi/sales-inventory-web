# Sales Inventory Management System – Frontend

A web-based application for managing sales and inventory operations, built with React and TypeScript.

## Technologies

- Node.js 24.x
- npm
- React 19
- TypeScript 5.9
- Vite 7
- Tailwind CSS 4
- React Router 8
- ESLint 9

## Prerequisites

Make sure the following software is installed:

- Node.js 24.x
- npm (comes with Node.js)
- Git

## Installation

1. Clone the repository

2. Navigate to the project directory:

3. Install dependencies:

   ```bash
   npm install
   ```

## Environment Setup

1. Create a `.env` file in the project root.
2. Copy the configuration from `.env.example`.


## Running the Application

Start the development server:

```bash
npm run dev
```

The frontend will be available at:

http://localhost:5173/

## Available npm Scripts


 `npm run dev` => Starts the development server 
 `npm run build` => Builds the application for production 
 `npm run lint` => Runs ESLint to check code quality 


## Local URLs

 Frontend => http://localhost:5173/

## Known Limitations

- The frontend requires a running backend API for server-dependent functionality.
- API integration and application features are subject to ongoing development.
